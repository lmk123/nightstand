# 权限与网页脚本读写的数据

| 权限 | 用途 |
|---|---|
| `storage` | 保存加密的收藏列表、哈希匹配表和快捷链接设置（只用本地存储） |
| `history` | 删除受保护站点的浏览记录，这是核心功能 |
| `tabs` | 读取当前标签页的网址和标题以便添加；快速收起时找出并关闭受保护站点的标签页 |
| `alarms` | 定期做增量扫描 |
| `bookmarks` | 保存条目时统计并删除这个站点的书签；从书签导入 |
| `favicon`（仅 Chrome） | 从浏览器本地的图标缓存读取网站图标，显示在列表里 |
| 网页脚本，匹配所有 `http://*/*`、`https://*/*` | 遮住受保护的网页。事先不知道用户会收藏哪些网站，只能匹配所有网站；按站点申请权限反而会把受保护网站的域名写进扩展详情页的“网站访问权限”。安装时 Chrome 会提示“读取和更改您在所有网站上的数据” |

网页脚本只读取匹配表、`prefs`，以及在要遮住的网页上读取明文的 `links`（伪装的快捷链接和图标选择，只用其中的图标；`storage` 只能整键读取），不读取网页内容（只读写标签页标题，以便遮住时换成中性标题、显示时还原），只和后台交换“是否受保护 / 已显示 / 已遮住 / 是否在播放声音”这几种消息。整个扩展不发起任何网络请求，完全离线运行。网站图标也不例外：只读 Chrome 本地已缓存的图标，不会去网站上下载（见 `apps/extension/.context/popup/favicons.md`）。

给商店审核的英文权限说明在 `apps/extension/store/README.md`，改权限时两边一起改。

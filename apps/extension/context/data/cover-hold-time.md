# http 页面遮罩的等待时长

仅指在用户的一台 Mac 上用真实 Chrome 测得的数值，换机器（尤其是慢机器）需要重测。

测法：在真实 Chrome 里打开未受保护的 http 页面，记录从 `responseStart` 到遮罩脚本放开等待的时长。

| 日期 | 版本/改动 | 数值 |
|---|---|---|
| 2026-11-09 | 问后台（service worker 已唤醒） | 19.8ms |
| 2026-11-09 | 网页脚本本地算哈希（JS SHA-256） | 23.1ms |
| 2026-11-09 | 问后台（service worker 冷启动：空闲 ≥30s 后的第一个 http 页） | 47.8ms |

**从第一天起就做 i18n。** 所有界面字符串都经过 `apps/extension/src/platform/i18n.ts` 的 `t()`；组件里不能有硬编码文案。语言：`en`（`default_locale`，也是推导 `MessageKey` 的那个文件，所以那里缺 key 就是类型错误）、`zh_CN` 和 `zh_HK`（繁体中文，用香港用语）。每个 key 都要同时写进每一份 `_locales/*/messages.json`，占位符一致——`tools/check-locales.mjs` 在 `lint` 里强制检查。没有对应语言包的浏览器显示英文。Chrome 只认它自己的界面语言名，其中没有 zh_HK（香港用户的 Chrome 以 zh-TW 运行）：Chrome 直接跳过 zh_HK 文件夹，所以 Chrome 上的繁体中文用户看到的是英文；zh_HK 只可能在 Firefox 里生效（未实测）。只放 zh_HK、不复制成 zh_TW 是用户的决定，不要自行改。chrome.i18n 没有复数形式：英文里的计数写成 "Label: $COUNT$" 或 "(…$COUNT$)"；不分单复数的缩写单位可以直接跟在数字后面（"$COUNT$ min"）。

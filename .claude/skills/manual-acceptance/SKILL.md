# 手动验收清单

每个涉及相关功能的里程碑，都要在真实浏览器里逐项过一遍。测试域名用 `example.com` / `example.org` 之类。

1. 添加 `example.com`（整个站点），访问 `https://www.example.com/foo`，然后：`chrome://history` 搜 "example" → 无结果；新标签页地址栏输入 `exa` → 没有历史提示；新标签页“常去网站” → 没有它。
2. 添加之前先访问某个网站并加书签，再添加它：保存提示给出历史里的网页数和书签数；确认后两者都消失。
3. 访问 `evil-example.com` 这类外观相似的域名：它**不能**被清理。
4. 锁定状态下访问受保护站点：历史照样被清理。
5. 锁定时打开 popup：只看到快捷链接；口令输错没有任何提示；输对口令按回车即解锁。
6. 解锁后关闭 popup 再打开：回到伪装界面，需要重新输入口令。
7. 全新安装，第一次打开 popup：进入引导（而不是伪装界面）。引导中途关闭 popup 再打开：引导从头开始，存储里没有保险箱数据。
8. 按下快速收起（panic）快捷键：匹配的标签页被关闭，打开着的 popup 也关闭。
9. 扩展管理页上没有任何暴露用途的信息（名称、描述、图标），使用过程中从未打开过扩展标签页。
10. 打开受保护站点（https 和 http 各一个）：加载过程中任何时刻都看不到页面内容，直接出现遮罩；标签页标题是“新标签页”、已静音。点“显示页面”后内容和声音恢复；鼠标移出网页、切换标签页、切到别的应用、超过设置的时长（默认 1 分钟）不操作后都重新遮住并静音；标签页在播放声音时不因无操作而遮住，停止播放后约 12 秒遮住（中途停几秒再继续不遮住）；用鼠标点别的标签页再切回来时，看不到页面内容闪一下；鼠标移到网页上的右键菜单、下拉选项上时不会遮住。普通网站加载时没有可察觉的闪白。

另外还要验证，并记录到 `.context/history/cleaning.md` 的“已知限制”里：历史删除后，Chrome 地址栏是否仍会从书签、已打开的标签页、搜索引擎联想（服务端，和 Google 账户活动有关）或地址栏的“快捷方式”数据库提示受保护站点；以及开启 Chrome 同步时 `history.deleteUrl` 是否也会删除其他设备上的记录。

第 10 项过完后，把 `apps/extension/.context/cover/cover-behavior.md` “已知限制”里标着“待手动确认”的遮罩相关项（首次绘制前就盖上遮罩、窗口失去焦点、Firefox 上的遮罩和静音等）按实测结果改掉，写上日期和浏览器版本。

# 项目文档入口

做新需求、评估方案前，先看有没有相关的：
- 地址栏的书签、已打开标签页、搜索联想提示不归历史清理管；“常去网站”、快捷方式数据库、同步删除仍待手动确认。评估和历史清理、地址栏提示、书签、同步有关的需求前读 `.context/history/cleaning.md`
- 锁定时靠明文的加盐哈希匹配表清理，它防不住拿常见域名比对；数据密钥只在 popup 内存里。评估和口令、恢复码、加密、锁定时的匹配有关的需求前读 `.context/vault/encryption.md`

只在改代码时才用得上的文档由各领域的 `.claude/rules/<领域>/context-index.md` 在碰到相关代码时带出来，不在这里列。
